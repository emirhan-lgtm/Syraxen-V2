# Syraxen V2

Syraxen yazılım ajansı için çok sayfalı, dark temalı tanıtım sitesi.

```
index.html              site (HTML + CSS + JS tek dosya)
assets/logo.svg         logo
assets/favicon.svg      favicon
content/icerik-tr-en.md tüm site metinleri (TR / EN)
nginx/syraxen.conf      VPS için nginx ayarı (Vercel kullanılıyorsa gerekmez)
docs/yayin-notlari.md   yayın adımları ve yapılacaklar
```

- Sayfalar: Ana Sayfa, Hizmetler, Projeler, Hakkımızda, İletişim
- TR / EN dil desteği
- İletişim formu mesajı doğrudan Formspree'ye gönderir
- Yayın: Vercel (önerilen), GitHub Pages (Settings > Pages > `main` / root) veya VPS + nginx
